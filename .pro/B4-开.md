## 2. B4.1 `why` 走 compose

### 2.1 先抽一个共用渲染函数（防止两处再次漂移）

`main.rs` 里把 `cmd_ask`（现 338-414）的打印块抽出来：

```rust
/// 打一条答案（首行标签 + judgment + scope + 依据），返回退出码。
/// `ask` 与 `why` 共用，保证两个命令永远说同一句话。
fn render_answer(subject: &str, ans: &datacore::query::Answer) -> u8 {
    let (label, code) = match &ans.outcome {
        datacore::compose::Outcome::Held => ("held", 0u8),
        datacore::compose::Outcome::Refuted => ("refuted", 1),
        datacore::compose::Outcome::Uncertain(r) => (
            match *r {
                "no_data" => "no_data",
                "expired" => "expired",
                "conflict" => "conflict",
                "coverage_short" => "coverage_short",
                _ => "uncertain",
            },
            2),
    };
    println!("{label}: {subject}");
    if let Some(j) = &ans.main {
        println!("  judgment {} kind={} verdict={} coverage={}/{}",
                 j.id, j.kind, j.verdict.as_str(), j.coverage_read, j.coverage_total);
        let gran = if j.scope.granularity.is_empty() { "-" } else { j.scope.granularity.as_str() };
        println!("  scope={gran} objects={} env={}", j.scope.objects.len(), j.scope.env.len());
    }
    for e in &ans.evidence {
        println!("  <- [{}] {} ({})", e.polarity, e.premise, e.instrument);
    }
    code
}
```

`cmd_ask` 改成：`let ans = query::ask(...)?; let code = render_answer(subject, &ans); Ok(ExitCode::from(code))`。

### 2.2 `cmd_why`（现 326-363）改成"先 ask，再补明细"

```rust
fn cmd_why(root: &PathBuf, path: &str) -> anyhow::Result<ExitCode> {
    let store = Store::open(root)?;
    let subject = if path.starts_with("file:")
        || path.starts_with("symbol:")
        || path.starts_with("doc:")
    {
        path.to_string()
    } else {
        format!("file:{path}")
    };

    let ans = query::ask(&store, &subject, None)?;
    let rows = store.changes_for(path)?;

    // 1) 有判断：结论以 compose 为准（与 ask 一字不差）；change 明细只作补充
    if ans.main.is_some() {
        let code = render_answer(&subject, &ans);
        if !rows.is_empty() {
            println!("  改动 {} 次（最近 10 条）：", rows.len());
            for r in rows.iter().take(10) {
                println!("  {} {} {} <{}> {}", &r.commit_hash[..8.min(r.commit_hash.len())],
                         r.status, r.at, r.author, r.subject);
            }
        }
        return Ok(ExitCode::from(code));
    }

    // 2) 没判断但有 change 行（老库/只 ingest 过）：保守报 held + 明细
    if !rows.is_empty() {
        println!("held: {subject}（只有 change 记录，没有判断；建议跑一次 ingest）");
        for r in rows.iter().take(10) { /* 同上 */ }
        return Ok(ExitCode::SUCCESS);
    }

    // 3) 都没有：保留原来的三态口径（not_git / shallow / not_ingested / refuted）
    if !collect::git::is_repo(root) { println!("uncertain: 不是 git 仓库（no_git）"); return Ok(ExitCode::from(2)); }
    if collect::git::is_shallow(root) { println!("uncertain: 浅克隆，历史不完整（shallow）"); return Ok(ExitCode::from(2)); }
    let scanned = store.get_meta("scanned_commits")?.and_then(|s| s.parse::<i64>().ok()).unwrap_or(0);
    if scanned == 0 { println!("uncertain: 还没 ingest（not_ingested）"); return Ok(ExitCode::from(2)); }
    println!("refuted: 在已扫描的 {scanned} 个提交里，没有改动触及 {path}");
    Ok(ExitCode::from(1))
}
```

## 3. B4.2 `docs`/`parse` 用文件 mtime 当 `at`（幂等）

### 3.1 采集层：把 mtime 带出来

`collect/src/docs.rs`（现 4-8）：

```rust
pub struct Doc {
    pub path: String,
    pub title: String,
    pub excerpt: String,
    pub mtime: i64,   // 文件最后修改时间（unix 秒）；采集时刻不是观测时刻
}
```

walk 里 `out.push(Doc { …, mtime: mtime_secs(&p) })`，工具函数：

```rust
fn mtime_secs(p: &Path) -> i64 {
    p.metadata().and_then(|m| m.modified()).ok()
        .and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok())
        .map(|d| d.as_secs() as i64)
        .unwrap_or(0)
}
```

`collect/src/parse.rs`（现 5-10）：`Symbol` 加 `pub mtime: i64`；`parse_file`/`collect_nodes` 多传一个 `mtime: i64`（每个文件读一次 metadata，文件内所有符号共享；`file_symbols` 传 0 即可——verify 只用它判存在）。

### 3.2 CLI：用 mtime 当 at，并过期旧的

`cmd_docs`（现 240-277）：

```rust
let docs = collect::docs::scan(root, limit);
let scan_at = docs.iter().map(|d| d.mtime).max().unwrap_or_else(datacore::store::now_secs);
let src = Source { id: source_id(&repo, "docs", scan_at), instrument: "docs".into(), .. time: scan_at };
store.put_source(&src)?;                     // 一次扫描一个源，重跑同 mtime → 同 id
for d in &docs {
    let at = if d.mtime > 0 { d.mtime } else { scan_at };
    let subject = format!("doc:{}", d.path);
    let j = judgment_row(&repo, &subject, "doc", Verdict::Held, at, 1, 1, scope_of(vec![d.path.clone()], "file", &repo));
    store.put_judgment(&j)?;                 // 同 at → 同 id → DO NOTHING（幂等）
    store.put_evidence(&Evidence { /* 同现在，source_id: src.id */ })?;
    store.expire_older_than(&subject, Some(&j.id), at)?;   // 文件改过 → 旧判断过期
}
```

`cmd_parse`（现 290-324）同型：`scan_at = syms.iter().map(|s| s.mtime).max()…`；每个 symbol 的 `at = s.mtime`；evidence premise 里加 at（`def:<path>:<line>:<kind>:<at>`，避免不同版本同 id）；`expire_older_than(&subject, Some(&j.id), at)`。

### 3.3 `expire_older_than` 加保护（必须）

`store.rs`（现 385-399）两支 SQL 都加 `AND at <= ?1`：

```sql
UPDATE judgment SET expires_at = ?1
WHERE subject = ?2 [AND id <> ?3] AND (expires_at IS NULL OR expires_at > ?1)
  AND at <= ?1          -- 只许过期"不晚于新观测"的旧判断；否则会撞 DDL 或把未来判断误杀
```

理由：mtime 可能早于旧判断的 `at`（老库是 `now` 写的），不加这条会 `expires_at >= at` 报错或误杀。

### 3.5 测试（确定性，不靠 sleep）

用 `File::set_modified`（Rust 1.75+，工作区 rust-version 1.80）设 mtime，别 sleep：

| 测试 | 断言 |
|---|---|
| `docs_import_is_idempotent` | 1 个 md，跑两遍 docs → judgment/evidence/source 数不变 |
| `docs_edit_makes_new_judgment_and_expires_old` | 跑一遍后 `set_modified(now+10)` → 再跑 → 该 subject 2 条判断，旧的 `expires_at` = 新 at，`ask` 仍 held |
| `parse_import_is_idempotent` | 1 个 rs（`fn f(){}`），跑两遍 parse → 数不变 |
| `expire_older_than_skips_newer_at` | 插 at=100/200 两条，`expire_older_than(subject, Some(id200), 150)` → 只有 at=100 被过期，at=200 不动（不撞 DDL） |
