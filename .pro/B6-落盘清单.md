> 本批只落**文档**，不动代码、不动 `record` 解析、不建 checker。
> 源文件（内容以此为准）：
> - `.pro\模板-决策记录.md`
> - `.pro\示例-带断言.md`
> - `.pro\断言文法.md`（checker 契约，留在 .pro，不进 demo）
> - `.pro\exp\e4_claims.py`（v2）、`.pro\out\e4_v2.txt`、`.pro\out\e4_v2_sim.txt`

## 1. 要落盘的两个文件（照抄，别改）

| # | 目标路径 | 来源 | 说明 |
|---|---|---|---|
| 1 | `D:\projects\demo\docs\decisions\_模板.md` | `.pro\模板-决策记录.md` | 用户抄模板用；下划线开头 → `record` 不导入 |
| 2 | `D:\projects\demo\docs\decisions\_示例-带断言.md` | `.pro\示例-带断言.md` | 断言文法示例；同样不导入 |

**为什么下划线**：`record` 只扫 `D-*.md`（`record.rs::scan`：`name.starts_with("D-")`），所以 `_模板.md` / `_示例-带断言.md` 不会变成 judgment。**不要**用 `jw record _模板.md`（单文件模式不看文件名，会用占位日期报错）。

## 2. 对现有数字的影响（先知道，别当破坏）

| 动作 | 影响 |
|---|---|
| 复制两个 md 进 `docs/decisions/` | `record` 下次跑仍是 **11 条**（不导入 `_*`）；`cargo test` 不变（42） |
| 下次跑 `run.cmd docs D:\projects\demo` | 会多出 **2 条 doc 判断 + 2 条依据**（模板与示例本身也是文档），于是 4040/4069 → **4042/4071**。这是正常增长，不是回归；不想变就**先别跑 docs** |
| 下次跑 `run.cmd parse` | 不变（没有新 .rs） |
| `E4 v2` | 断言统计会从 0 变成 6（3 模板 + 3 示例），但 `importable=0` → **checker 门槛仍不满足**（模板/示例不导入） |

## 3. 验收步骤（照做，贴原始输出）

```powershell
# 1) 复制两个文件（内容照抄，逐字）
#    源：D:\projects\jingwei\.pro\模板-决策记录.md
#    源：D:\projects\jingwei\.pro\示例-带断言.md
# 2) 确认 record 不导入它们
run.cmd record D:\projects\demo\docs\decisions D:\projects\demo
run.cmd stat  D:\projects\demo
# 3) 跑 E4 v2（真实 demo；门槛数字）
& $py .pro\exp\e4_claims.py
# 4) 跑 E4 v2 的模拟落盘（把两个 _ 文件和 11 条记录放一起，验证文法；不碰 demo）
& $py .pro\exp\e4_claims.py "D:\projects\jingwei\.pro\tmp\e4sim" ".pro\out\e4_v2_sim.txt" "D:\projects\demo"
# 5) 回归
cargo test --workspace

```

**期望**：
- `record` 仍 `imported 11 records (11 decisions, 15 hypotheses)`；`stat` judgment 4040 / evidence 4069（没跑 docs 的前提下）
- E4 v2 真实：`断言行总数=0  importable=0 → 门槛①未满足`
- E4 v2 模拟：`断言行总数=6  importable=0  malformed=0  true=6 falsified=0 unverifiable=0`（文法通过，门槛①仍未满足）
- `cargo test` 42 绿；`check` 四项 0

## 4. 用户写第 1 条真记录后，看哪两个数

```powershell
& $py .pro\exp\e4_claims.py
```
1. **`importable_assertions ≥ 1` 且其中 `path_absent`/`symbol_exist` ≥ 1**（门槛①）；
2. **`unverifiable == 0`**（门槛②）。

两个都满足才允许开 `claim` kind + checker；`falsified` 不要求 ≥1（记录写对时断言应当全真，checker 的价值在以后漂移时翻）。见 `.pro\断言文法.md §4`。
