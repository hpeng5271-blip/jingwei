# D-20261020-04 · 跨文件限定名：按段解析，失败带段位

- 决策者：`deepseek-v4-pro`（学习 #5，rust-analyzer `PathResolution`）
- 执行者：`deepseek-flash`
- 触发：债 0.28（`mod.CONST` / `pkg.mod.Class.attr` 只在同文件认得）
- 状态：**尝试后卡住（2026-10-20 06:10）**——见文末"卡点"；代码已回退，仓库回到绿

## 问题

Python 侧 `Cfg.DEBUG` 能建 `references` 边（同文件），但 `from pkg import mod; mod.CONST` 认不出来。
两种错法都要避免：

- **乱猜**：把最后一段名字丢进全图按名撞 → 同名多处必然错，还标 High；
- **全放弃**：情报全丢，用户看到的是"没有引用"，而真相是"没解析到"。

## 决定

**按段解析，每段失败都记位置**；拿不到就 `Unknown{ at: 段 }`，不降级成"没有"。

```
res(name, current_module):
  for seg in name.segs[:-1]:
    next = resolve_module(current_module, seg)   # 走已有的 depends_on 边
    if next is None: return Unknown(name, at=seg)
    current_module = next
  last = name.segs[-1]
  return lookup(current_module, last) or Unknown(name, at=last)
```

## 必须放弃（一律 Unknown，不猜）

| 情形 | 为什么 |
|---|---|
| 前缀是**未索引的外部包** | 没有它的符号表，猜就是编 |
| 动态导入（`__import__` / `importlib` / `getattr` / `import *`） | 运行时才知道名字 |
| 别名被重绑 / 条件导入 | 同名多义 |
| 前缀落在**没有属性表**的值上（函数、字符串） | 属性集不可枚举 |
| `sys.path` 歧义（同名包多处） | 解析结果不唯一 |

## 实施步骤（每步可单独验收）

1. **记录完整路径**：`parse_python` 把 `a.b.C` 记成段列表（不再只留最后一段）；
   → 必须 bump `EXTRACTOR_VERSION`（旧图会跳过）。
2. **解析**：`resolve.rs` 加 `resolve_qualified`，前缀走 `depends_on`，逐段落 `Unknown{at}`。
3. **边的置信度**：全段命中 = `High`；只中前缀 = **不建边**，记 `unresolved_refs`（已有计数）。
4. **测试（红先写）**：
   - 正例：`pkg/mod.py: CONST` + `main.py: mod.CONST` → references 边落在 `pkg/mod.py` 的 CONST；
   - 反例①：`import *` → 无 edges，`unresolved_refs` +1；
   - 反例②：前缀是不存在的包 → 无 edges，且 `Unknown.at == 第一段`。
5. **回归**：flask 的 `references` 边数不减少；positions 仍 0 错。

## 验收（缺一不算）

- 红先写的测试在改之前**确实红**（贴输出）；
- flask / tauri 各跑一次索引 + `positions`，0 错；
- 全量门禁 8/8。

## 不做

- 不做类型推断（`x.foo` 的 `x` 是什么类型）——那是另一个数量级；
- 不做跨语言（Python 调 Rust）——图谱里没有这个事实。

## 卡点（第一次真做，停在这里）

按上面的计划改到"解析 + 建边"都通了（调试确认 `cfg::DEBUG` 这个引用**确实被抽出来**），
但边建不出来，原因不是解析，是**符号本身不存在**：

```
node symbol:main.py#run          | run
node symbol:pkg/cfg.py#helper    | helper
（没有 symbol:pkg/cfg.py#DEBUG）
```

`parse_python` 只把**类体里的常量**收成符号，**模块级常量 `DEBUG = True` 根本没进图谱**。
所以"前缀解析对了"也没有落点——`references` 边的 dst 无处可指。

两条路（都需要更大的改动，不适合深夜快手）：

1. **扩符号**：把模块级赋值（至少全大写 / 带注解的）收成 `sym:"const"`；
   代价：flask 符号数再涨（当前 1,920），positions 要重跑，债表 0.17 的"类体常量"逻辑要合并；
2. **只做类属性**：限制成 `mod.Class.attr`，绕开模块级常量；覆盖面小很多。
