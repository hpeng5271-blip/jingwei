# D-20261023-05 事件的项目归属：加 `root` 字段

- 日期：2026-10-23
- 决策者：决策 pro（`971be04a`）
- 执行：flash

## 问题

「学习进度」要按项目分组，但事件里 `key` 只有相对路径（`src/a.rs`），**没有项目标识**。
两个项目里的同名文件在事件流里是同一个 key，切项目筛不出来。问题不在视图，在**采集时就没记归属**。

## 三个选项与取舍

| 选项 | 做法 | 代价 | 结论 |
|---|---|---|---|
| **1 加字段** | `Event` 增 `root`；老事件 `None` | 改 schema + 明确迁移口径 | **选它** |
| 2 key 复合 | key 写成 `root + 分隔符 + 路径` | 所有读侧都要拆，点击回文件多一步解析；污染 key 语义 | 否决 |
| 3 不做 | 降级为"全局进度"，界面写清"跨项目" | 零改动，但把混淆留给用户 | 否决 |

## 裁定内容

1. `root` 是采集时就存在的事实，**由引擎层强制写入**（不是界面补）；
2. 老事件 `root = null`，视图里归「未知项目」分组，**可见、不隐藏**——比伪造诚实，历史数据仍可点回文件；
3. 切项目只显两组：**本项目** + **未知项目**；属于别的项目的文件**不显示**。

## 落地

| 层 | 提交 | 内容 |
|---|---|---|
| schema | `99c2e50` | `Event.root` + 老格式兼容断言 |
| 引擎强制 | `b587025` | `Recorder::with_root`，`record()` 自动补；无根写 null |
| 界面上报 | `b86c729` | `event_note` 增 `root` 参数，写进文件 |
| 分组判据 | `95c6727` | `Snapshot::progress_in(root)`：三分（本项目/未知/别人） |
| 展示 | `6cfb45c` | 界面两组渲染 + `serve` 收 `root` 参数 |

## 验收断言

- `老事件没有_root_也能读`：老 JSON → `None`，新 JSON → `Some`
- `带项目根的recorder_每条都带_root`：`with_root` → 每条带；`new` → `None`（不伪造）
- `event_note_写进去_且_open_去重`：界面带根写出的文件里有 `"root":"D:/proj"`
- `切项目只显本项目与未知项目`：本项目归组、没根归未知、别的项目不出现
- `未知项目单独成组且可见`（界面）：两组同时出现，都可见
