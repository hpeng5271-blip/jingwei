# 决策记录（pro 出决策，flash 执行）

> **规则**：每一件"不可逆 / 跨模块 / 判据变更"的事，先有这里的一张记录，才允许执行。
> 没有记录就动手 = 违规（门禁不查这个，但账本会显示"无决策记录的轮次"）。

## 记录格式

```markdown
# D-YYYYMMDD-NN · 标题

- 决策者：deepseek-v4-pro（子智能体，只读）
- 执行者：deepseek-flash（主会话）
- 触发：不可逆 / 连续失败 2 次 / 人点名 / 跨模块无测试
- 状态：待执行 | 执行中 | 已完成（附证据） | 作废

## 决策
一句话，必须可判定。

## 为什么不是别的
对每个被否决的选项各一句。

## 验收（机器可判）
- 命令：
- 通过线：
- 失败意味着什么：

## 最可能翻车点
一句。

## 执行记录
- [ ] 步骤 1
- [ ] 步骤 2
- 证据：（门禁表 / 命令输出行号）
```
