根因是 `Store::open` **会建库**，而读路径用了它：于是"查不了"被压成"错了"，还在人家目录里留一个空 `.jingwei/`。
修法是 `open_graph()`（库不存在或 0 符号 → None）+ `query::open_for_query`（只读）。
判据不靠记性：事故账本里那三条都带可复跑的命令。
