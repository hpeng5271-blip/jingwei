## 怎么维护

- 新文件落进来 → 在上面对应类里加一行，写"干什么用的"。
- 一份被取代 → 挪到"史料"表并加横幅，**不删**（链接与引文都指着它）。
- 想真正合并正文：先 `grep` 谁引用它，再决定是合并还是只加横幅；合并要一次改完所有指向。
- 2026-10-22 的示范：两份 `进展报告` 合成 `进展报告-2026-10.md`——**原文一个字没删**，只在前面加时间线；原件 `git rm`，引用一次改完（`docs/process/README.md`）。
- 第二例（同一天）：减法重构进度 + 接缝契约审计 合成 专题-减法与接缝-2026-10-21.md；改完用一条小脚本扫 docs/ 里所有相对 .md 链接，确认**没有断链**。
- 合并/搬动之后跑 `node tools/check-links.mjs`：它只查 `.md` 相对链接，能抓住 grep 抓不到的"路径写错"式断链。
