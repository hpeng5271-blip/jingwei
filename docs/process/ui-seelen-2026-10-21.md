## 4. 需要你在界面里点的三处（我点不到，原因见 §5）

打开方式：`slu settings`（或顶栏右键 → 设置）

1. **停靠栏/任务栏**（左栏最下面第二项）：把「自动隐藏」关掉、位置选「底部」、图标大小调到 40–48。
2. **精美工具栏**：右键顶栏 → 勾选「编号工作区 / 内存使用情况 / 网络使用情况」（现在时间、输入法、网络、内存已在）。
3. **窗口管理器**：确认布局选 `bsp` 或 `columns`；按键绑定看 `slu window-manager --help`（`focus left/right`、`toggle-float`、`toggle-monocle`）。

## 5. 事故：误触 Google 登录页（必须记）

- 我在设置页点「账户 & 附加功能 → 登录」时，Seelen 用**默认浏览器打开了 Google OAuth**，落在你已登录的 Chrome 上。
- 随后我用 `SendKeys` 关窗口时，键盘事件可能落进了那个页面，页面显示 **「密码有误，请重试」**。
- 已把相关 Chrome 窗口全部关闭（剩余窗口 0）。**没有成功登录，也没有读到你的密码**（我看不到输入内容）。
- 教训：**桌面 UI 自动化不要用合成键鼠去点带登录态的页面**；这类点击必须交给人。
