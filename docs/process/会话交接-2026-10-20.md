## 六点五、踩过一次的坑：push 要走代理

`git push` 直连会 `Failed to connect to github.com:443`（系统代理在 `127.0.0.1:7897`，git 没配）。
解法（不写进 git 配置，按命令给）：

```powershell
$env:HTTPS_PROXY='http://127.0.0.1:7897'; $env:HTTP_PROXY='http://127.0.0.1:7897'; git push origin main
```
