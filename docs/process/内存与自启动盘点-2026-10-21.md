# 内存与自启动盘点 · 2026-10-21

> 结论先给：**能自己关的我已经关了；最大的两块（我自己 3.7 GB、Seelen 1.2 GB）都需要管理员权限或重启会话。**

## 1. 现场（按进程组，工作集）

| 进程组 | 进程数 | 内存 |
|---|---|---|
| **DeepSeek Harness**（就是"我"所在的应用） | 7 | **4,688 MB** |
| **msedgewebview2**（含 Seelen 的 14 个） | 23 | 1,623 MB |
| svchost（系统） | 85 | 1,522 MB |
| MsMpEng（Defender 扫描） | 1 | 529 MB |
| explorer | 1 | 334 MB |
| **seelen-ui** | 1 | **197 MB**（＋它的 WebView2 子进程约 1,056 MB） |

空闲内存：**5,514 MB / 16 GB**。

## 2. 做了什么

| 动作 | 结果 |
|---|---|
| 杀 `seelen-ui` | 3 秒内被 `slu-service` 拉起 → **无效** |
| 杀 `slu-service` | **Access denied**（它以最高权限在跑） |
| 杀 Windows 壳组件（SearchHost 等） | **没做**——它们会被秒拉起，只会抖一下桌面 |
| 关自启动（HKCU Run） | 查过，**是空的**，没有可关的 |

**原因是权限**：Seelen 的自启动不是注册表 Run，而是计划任务
`\Seelen\Seelen UI Service`（RunLevel=Highest）。普通权限既停不了服务、也禁不了任务。

脚本已备好：`docs/process/关掉-Seelen-管理员.ps1`（右键管理员 PowerShell 跑一下就行，含可选卸载）。

## 3. 自启动清单（现状）

| 位置 | 项 | 建议 |
|---|---|---|
| HKLM Run | `SecurityHealth`（Defender 托盘） | 留 |
| HKLM Run | `RtkAudUService`（声卡） | 留 |
| HKLM Run | `Everything -startup` | 留（你自己装的，好用） |
| HKLM Run(x86) | `wintray`（wnasst，来路不明） | **建议关**（脚本里第 4 行） |
| 计划任务 | `\Seelen\Seelen UI Service` | **建议禁用**（脚本第 1 行） |
| 计划任务 | Kaspersky / DirectX / 语言同步等 | 留（系统/杀软） |
| Startup 文件夹 | 空 | —— |

## 4. 我自己那 4.7 GB 怎么来的

- 主进程 3,697 MB：**这个会话的上下文**（今天从早到晚的长对话、门禁输出、截图都在里面）
- 其余 5 个进程 38–464 MB：渲染/插件
- 结论：**这不是泄漏，是"这个会话太长"**。真要降，唯一有效动作是**结束当前会话、开新的**（我这边无法自我重启）

## 5. 一句话

> 我从 5.5 GB 空闲里能抢回来的只有"重启会话"和"管理员跑那个脚本"两条；
> 前者省 ~3.5 GB，后者省 ~1.2 GB。**两条都超出一个普通权限进程的能力边界**——这不是不干，是干不了。
