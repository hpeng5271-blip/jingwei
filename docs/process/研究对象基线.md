## 4. 已知边界（不许说成"支持"）

- `index` 只解析 `.rs` / `.py`；**Node / Java 只判不画**（能识别项目类型，不进图谱）；
- Python 的角色统计只看 `calls`，属性访问边未建；
- LSP 只做定义 / 引用 / hover / 诊断推送，没有补全与重命名；
- 位置回读的"位置不准"是**允许**的第三态（名字在文件里但不在该行），不等于错；
- **`positions` 目前只核 Rust 符号**：flask 上 `positions` 报"核了 0 个符号"，而图谱里有 1,580 个（Python 侧未被位置校验，见债表 0.14）。

## 5. 怎么用它当裁判

每次改动后跑一遍 §2，对照 §3 的数字：**文件/符号数不变、调用数不降**才算没退化；
`positions` 的"对不上"必须为 0。数字对不上就是退化，不接受"看起来差不多"。
