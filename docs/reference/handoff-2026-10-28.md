## 7. 暗坑（新会话必看，全部踩过）

1. `String::truncate` 非字符边界 panic → 只读 N+4 字节 + `is_char_boundary` 回退。
2. `store.count("<表>")` 有白名单，白名单外 + `unwrap_or(0)` → 恒 0（曾让 stats 假 0）。
3. INNER JOIN 吞悬空行 → 安全不变量假 0；用 LEFT JOIN + `ifnull`。
4. `read_dir(root.join(rel))` 无越界检查 → canonicalize + starts_with。
5. tree-sitter 有 `links`，全图只能一版；语法包只依赖 `tree_sitter-language`。
6. 用 sha256 判活，不用 mtime（`copy2` 保留旧 mtime）。
7. cargo/`jw.exe` 并发 → 假红；门禁前断言进程 0。
8. 状态只进 HANDOFF，不许写进代码注释当台账。
9. Tauri v2 参数是 camelCase：`root_ready` ↔ `rootReady`。
10. UIA 点不到 WebView 内按钮 → 用 `cdp_step.py`（CDP 注入），不改产品代码。
11. `jw serve` 启动先吐一行问候，客户端要跳过再匹配 `ok`。
12. `.cmd/.bat` 需 `cmd /C call "<path>"`；`pin` 必须拒绝 shell 元字符。
13. PowerShell 5.1 读无 BOM 的 UTF-8 `.ps1` 会坏中文 → 所有 `.ps1` 存**带 BOM**。
14. 删函数/模块必须连 `#[tauri::command]`/`mod` 一起切，删前打印行范围（`.pro/exp/del_fn.py`）。
