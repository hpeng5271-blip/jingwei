- **项目**：`impact`（文件/符号/目录三种目标；direct / transitive depth≤2 / tests 文件级 / importers / completeness；目录明细截断 100 + `direct_truncated`）、`tests-for`（符号级静态可达，`via` 逐跳可核）、`coverage`、`stat`、`check`、`project`。

## 4 已知边界（不许读成更强的东西）

1. `card <empty-or-missing-dir>`：全 0 且 **exit 2**（与 `edges` 同风格），JSON 不带 `reason` 字段——按现状记录。
2. `card <dir>` 范围 >300 文件：`definitions` **退回 DB 下界**（不重解析），`symbols.definitions_note` 会显式标注；`files` 仍是磁盘 `.rs` 数。
3. `card` 是**写焦点槽**的命令（更新 `ui.preview`/`ui.last_focus`，DB mtime 会变）——不是严格只读；批量脚本想知道这点时以 mtime 为准。
4. 调用图 v1.5：只认**同文件/`use` 绑定/全仓唯一 fn 名**；方法调用、宏生成、trait 动态分发、std 内部实现一律不解析（保持 `?call`）。
5. `tests-for` / `impact.tests` 是**静态可达 / 文件级**，不是运行覆盖；文案固定写明。
6. 派生数据（edge/symbol/doc/dep、gap/capability 视图）可重建；`rules` 变化会全量重建 edge。
7. range impact 的 `direct`/`transitive` 明细最多各 100 条（`direct_truncated`/`transitive_truncated` 标注），`direct_total` 是全量。
