# 不要账号也能读的社区通道（2026-10-22 实测）

> 目的：把"社区资源"变成**可复跑的通道清单**，而不是"听说哪儿好"。
> 全部走本机代理 `127.0.0.1:7897`；全部**不需要登录**；工具：`tools/web.mjs`。

## 一、实测结果

| 通道 | 状态 | 命令 | 备注 |
|---|---|---|---|
| StackOverflow / StackExchange | ✓ | `so "<q>"` · `soq <id>` | 页面被 Cloudflare 护着，但 **API 的 `filter=withbody` 能拿正文** |
| GitHub issues | ✓ | `gh "<q>" [--repo o/n]` | 技术问题第一优先（真实现场） |
| Hacker News（Algolia） | ✓ | `hn "<q>"` | 讨论质量高，适合"为什么" |
| Discourse 论坛 | ✓ | `discourse users.rust-lang.org "<q>"` | Rust/Python 官方论坛 |
| **Reddit（PullPush 档案）** | ✓ | `pullpush "<q>"` | 拿到标题/分数/子版；**链接本身打不开**（Reddit 登录墙） |
| Lobsters | ✓ | `lobsters [tag]` | `hottest/newest/t/<tag>.json` 可用；`search.json` 返回 HTML（别当 JSON） |
| dev.to | ✓ | `devto <tag>` | 文章 API，适合工程实践 |
| V2EX（中文） | ✓ | `v2ex hot` | 只有热门接口；按关键词搜要开浏览器 |
| Reddit 直连 | ✗ | — | `403`（`.json`）/ 登录墙（HTML） |
| DuckDuckGo HTML | ✗ | — | 202 挑战页 |
| Bing RSS | ✗ | — | 返回垃圾结果 |
| Discord | ✗ | `discord` | 要 bot token；self-bot 会封号 |

**多源一条命令**：`node tools/web.mjs search "<q>"` → GitHub + SO + HN + PullPush。

## 二、用这个通道学到一个真问题（WebView2 缺失）

我们这台机器今天 WebView2 运行时被误删，现象是：**GUI 进程活着、窗口标题 `Error`、无 `msedgewebview2.exe` 子进程**。

社区口径（SO 76065661，正文经 `soq` 取到）：

> `WebView2RuntimeNotFoundException: 'Couldn't find a compatible Webview2 Runtime installation to host WebViews.'`
> `HRESULT: 0x80070002`（找不到文件）

**这条对上了我们的诊断**：不是"应用坏了"，是"宿主缺运行时"。
修复也印证：装回 Evergreen Runtime 后，窗口标题恢复真名、子进程出现。

> 纪律：这是**社区证据**（`[已核实]`：我读了 API 返回的正文），但它不是判据；
> 判据仍是本机实测（标题/子进程/注册表 `pv`）。

## 三、结论

1. **不需要你的账号**：上面 8 条通道都是匿名可用的，Reddit 内容也能通过 PullPush 拿到。
2. **Discord 是唯一真缺口**：要么你建 bot（可撤销、可限频），要么人工看。
3. 抓取规矩（写死在技能里）：间隔 ≥3 秒、每小时 ≤60 次、只读、不互动。
4. 你贴过明文密码：**建议立刻改密 + 开两步验证**；我不需要它也能干活。
