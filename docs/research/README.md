# research/：外部一手来源（四类可信度，写清出处）

> 这里的每一份都回答"**别人原话怎么说**"，不回答"我们现在该怎么做"。
> 引用时按四类标注：**原话**（有原文/时间点）/ **转写**（语音或视频转写，可能听错）/
> **二手**（别人解读，可能夹带） / **查不了**（试过没拿到，写清查了什么）。

- [`一手来源.md`](一手来源.md)：来源清单与获取方式（哪本书、哪个视频、几分钟处）。
- [`原子能-学习来源摘录.md`](原子能-学习来源摘录.md)：原文摘录（带位置）。
- [`原子能-观点地图.md`](原子能-观点地图.md)：观点之间的关系（谁反驳谁）。
- [`原子能-转写要点.md`](原子能-转写要点.md)：**转写**——可信度低于原话，别当引文用。
- `atomen-catalog.json`：结构化条目（工具读取用）。

规矩：**没出处的不写进结论**；引用别人的话必须能指回这里的一行。
