# GUI 起不来/白屏先查 WebView2 运行时是否存在与版本达标

- 结论：诊断 Tauri GUI"窗口标题 Error / 无 msedgewebview2.exe 子进程"时，先判"宿主缺 WebView2 运行时"，再判"应用坏"；程序化检查用 GetAvailableBrowserVersionString + CompareBrowserVersions 判存在与版本下限。
- 为什么现在能用：本机 WebView2 运行时被误删已发生过一次（现象=窗口标题 Error、无子进程），GUI 冒烟需要这一条前置诊断，避免把"缺宿主"误报成"应用坏了"。
- 落点：`tools/smoke-pack.mjs`（`--gui` 分支，起 GUI 前先查运行时存在+版本）。
- 验证：无 WebView2 运行时（或版本过低）的机器上跑 `node tools/smoke-pack.mjs --gui`，输出"宿主缺 WebView2 运行时"而非"窗口 Error"。
