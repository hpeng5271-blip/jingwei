# adopted/：筛选方写这里（**可立即复用**的结论）

每条必须有四样，缺一样就不算 adopted：

```markdown
# <结论一句话>

- 结论：<可判定的一句话>
- 为什么现在能用：<当下的代码/文档/判据正好需要它>
- 落点：`<文件路径 或 命令>`（改哪、加哪、写进哪份文档）
- 验证：`<能跑的检查或断言>`
- 来源：`inbox/<文件>` 或 <URL>
- 采用时间：2026-10-22
```

**边界**：adopted 不能直接改门禁判据、不能改真源数字、不能改三态口径——
那类改动走 `docs/decisions/`（decision pro + 人）。
