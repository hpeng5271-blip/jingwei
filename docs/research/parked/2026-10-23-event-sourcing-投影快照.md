# 事件流是唯一真源，投影可重建；快照/outbox 加速重放与派发

- 结论：append-only 事件流是唯一真源，当前状态=重放事件得到（投影），可用快照加速重放、用 outbox 派发派生事件。
- 什么时候可以复用（触发条件）：给 usage.jsonl 做"周活跃/多维度统计"消费、或把 usage 从"一行一条"升级成"事件流+投影"时。
- 为什么现在不用：当前 usage.jsonl 只有一个投影（按命令计数），不需要快照/重建复杂度。
