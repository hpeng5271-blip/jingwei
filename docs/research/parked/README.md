# parked/：筛选方写这里（**暂时用不上**，但要好好存）

存的标准不是"看起来有用"，而是**写得出什么时候会用**。写不出触发条件的，是噪音，别存。

```markdown
# <结论一句话>

- 结论：<可判定的一句话>
- 什么时候可以复用（触发条件）：<例如"做启动性能优化时" / "债 0.42 常驻通道开工时">
- 为什么现在不用：<缺什么前提：没数据 / 没界面 / 没决策 / 成本不划算>
- 落点（将来）：`<文件或命令>`
- 来源：`inbox/<文件>` 或 <URL>
- 归档时间：2026-10-22
```

**到期检查**：每次做触发条件那件事时，先 `grep` 一次 `parked/`，别重新发明。
