# 知识流水线：读 → 筛 → 采用 / 存起来

> 2026-10-22 定的分工（人指定）：
> **读的人只负责取回原话**，**筛的人只负责判定"能不能马上用"**，**做决策的人不读原文**。
> 这样决策端不会被几十条帖子淹没，也不会把"某人的经验"当成事实。

## 三个格子

| 目录 | 谁写 | 写什么 | 下游怎么用 |
|---|---|---|---|
| [`inbox/`](inbox/) | **取信方**（低流量读） | 一份来源一个文件：URL、抓取时间、原文摘录、可信度（原话/转写/二手/查不了） | 筛的人读它，不读原文 |
| [`adopted/`](adopted/) | **筛选方** | **可立即复用**的结论：一句结论 + 为什么现在能用 + 落点（哪个文件/命令）+ 验证方式 | 直接进实现或文档 |
| [`parked/`](parked/) | **筛选方** | **暂时用不上**的：一句结论 + **什么时候可以复用**（触发条件）+ 来源链接 | 等触发条件满足再看 |

## 规则（写死，避免退化）

1. **inbox 不做结论**：只录原话与出处，禁止写"所以我们应该…"。
2. **adopted 必须带落点**：没有落点（改哪个文件/加哪条命令/进哪份文档）就不算 adopted。
3. **parked 必须带触发条件**：写不出"什么时候能复用"= 不是知识，是噪音，直接丢。
4. **不影响判据**：任何 adopted 都不能直接改门禁、改数字、改三态口径——那要 decision pro 与人拍板。
5. **流量**：≥3 秒/次、≤60 次/时、只读；公共实例 429 就等（`tools/web.mjs` 已按此写）。

## 一次完整流动（示例）

```
inbox/2026-10-22-webview2-not-found.md      ← 取信方：SO 76065661 原话 + HRESULT 0x80070002
adopted/2026-10-22-诊断口径-webview2.md      ← 筛选方：诊断时先看"运行时是否存在"，落点 tools/smoke-pack.mjs
parked/2026-10-22-tauri-启动优化.md          ← 筛选方：等做启动性能时再用（触发：首屏预算收紧）
```

## 谁在跑

- 取信：**另一个 flash 会话**（低流量，读社区）；
- 筛选：**另一个 pro 会话**（把 inbox 变成 adopted/parked）；
- 决策：**做决策的 pro `971be04a`**（复用同一个，不新建）+ 人；
- 执行：本会话（flash）。

## 引用规范（三字段，2026-10-23 定）

任何一条从 `inbox/` 走到 `adopted/` 或 `parked/` 的知识，**必须**带这三样：

| 字段 | 写什么 | 反例 |
|---|---|---|
| **来源** | URL 或"仓库内文件:行"；能点开、能复跑 | "网上说的" |
| **可信度** | 原话 / 转写 / 二手 / 查不了（四选一，见 `docs/research/README.md`） | "应该是对的" |
| **失效日期** | `YYYY-MM-DD`：一年后复核；社区答案会改、版本会变 | "永久有效" |

### 示例（照这个写）

```markdown
- 来源：https://stackoverflow.com/questions/67801230/…（StackExchange API，2026-10-23 取）
- 可信度：原话（只读到标题与元数据，正文未逐句核）
- 失效日期：2027-10-23
```

### 为什么要有这三样

缺来源 → 无法复核，等于传言；缺可信度 → 二手结论会被当成一手；缺失效日期 → 三年后还在被引用。
这三样是"知识能进门"的最低门槛，不是文风要求。
