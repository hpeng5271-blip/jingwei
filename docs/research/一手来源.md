# 一手来源：四个知识域各挖一口井（2026-10-20）

> 规矩：只收**一手**（论文/官方文档/源码/演讲原稿）；二手总结只当线索。
> 每条都给「借什么 + 读哪部分 + 用本项目怎么低成本验」。
> **可达性**标了实测：`200` = 今天取到过；`未核` = 没打开，引用时标明。

## 怎么用这份表

1. **一次只挖一口井**：选一条，读完 → 写一条"本项目能用/不能用"的结论进 `债表` 或 `设计.md`。
2. **必须带验证**：每条都要落到一个命令、一个用例、或一条判据；落不了就标"懂了就好"。
3. **不追全**：这张表是**索引**，不是书单；读不完不丢人，读一条用一条。
