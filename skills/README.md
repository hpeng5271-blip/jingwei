# skills · 二级技能树（L2）

> **三级分工，别混**：
> - **L1 骨架**（不在这个目录）：`框架.md` 怎么想 · `SOP.md` 怎么做 · `AGENTS.md` 现在什么状态
> - **L2 技能**（本目录）：一条能被复用的判断力。**每条必须有守卫**。
> - **L3 条目**：具体事故与判据细节，落在 `事故账本.md` 与测试注释里，不在这里新建文件。

## 一条 L2 技能的写法（四段，缺一段门禁就红）

| 段 | 要求 |
|---|---|
| `## 判据` | 一句话能判真假的规则 |
| `## 为什么` | 拿什么换来的（哪次事故 / 哪个实测数字） |
| `## 不适用` | **什么情况下它不该用**（没有适用域的判据一定会误报） |
| `## 守卫` | **一个真实存在的测试或门禁名**——必须能在 `tools/` 或 `crates/` 里 grep 到 |

**为什么必须有守卫**：这个仓库最贵的一课是「决定记在文档上，机器上什么都没发生」（见 `事故账本.md`）。
**没有守卫的技能 = 一条愿望。** 门禁会把它查红。

## 加一条新技能的门槛

1. 先有**至少一次真实事故**（或一次实测数字），再写；
2. 写清**不适用**；
3. 挂一个**现有或新增**的守卫；
4. 加进上面那张表——**表与目录集合必须相等**（门禁查）。
