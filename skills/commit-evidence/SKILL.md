# 提交：证据先行

## 提交前必须有

1. 门禁结尾表（`tools/gates.ps1`），且 `failed` 为 0。
2. `git status --porcelain` 干净或只剩本次要提交的文件。
3. 新判据/新测试：**改之前红过的输出**（没有就先补证明）。

## 提交信息

```
<一句话说改了什么>

## 为什么
<现象/根因；引用债表条目或决策记录>

## 证据
<门禁表 / 关键数字 / 测试数>
```

- 说明"为什么"，不写"改了哪些文件"（diff 已经说明）。
- 关联债表/决策：`债 0.32`、`D-20261020-04`。

## 红线

- 红着不提交；靠改数字/放宽判据过门禁的提交 = 事故。
- 不把未验证的结论写进提交信息。
- 提交后跑一次 `git log --oneline -1` 与 `git status`，确认落点。
