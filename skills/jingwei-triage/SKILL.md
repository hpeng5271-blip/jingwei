# 三态与卡点：是 / 不是 / 查不了

## 三态写法

| 状态 | 怎么写 | 反例 |
|---|---|---|
| 是 | 给结论 + 来源（文件:行 / 命令输出 / 边） | — |
| 不是 | 给反例或测试 | "应该不会" |
| **查不了** | 明说查不了 + 谁造成的（我们的空白 / 对方的缺口） | 把查不了写成"没有" |

## 什么时候必须写"查不了"

- 没索引、没数据、没读到的文件；
- 解析器不支持的语法形态（例如属性继承，债 0.33）；
- 外部来源取不到（风控/无字幕/无权限）。

## 卡点协议

1. 同一问题**失败两次** → 停。
2. 写清：现象、已试过什么、根因（若知道）、下一步由谁决定。
3. 落盘：`docs/reference/债表.md`（条目）+ `docs/process/要点-<日期>.md`（一行）。
4. 会话里明说"卡住，按规矩停"，**不许假装做完**。

## 不许

- 无自查就报错（错误必须带自查证据）。
- 生成"修复命令"让用户照着敲。
- 把推断写成原话（外部内容要标 `原话 / 转写 / 推断`）。
