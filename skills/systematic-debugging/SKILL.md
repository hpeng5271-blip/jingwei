# 系统化调试：不查根因，不许提方案

> 改编自 superpowers-zh 的同名技能（MIT）：https://github.com/jnMetaCode/superpowers-zh

## 铁律

**没走完第一步（复现 + 证据），不许写修复代码。**

## 四步（每步有产出，缺一步就停）

1. **复现**：用最小输入稳定复现；记下命令、输入、错误首行。
   - 判据：别人照抄能再见到同一个错。
2. **定位**：二分/加探针，找到**第一处与预期不符**的值或分支（不是最后报错的地方）。
   - 判据：能说出"因为 X，所以 Y"，并有一个反例。
3. **修因**：只改根因那一处；顺手重构放另一个提交。
   - 判据：反例变绿，且原有用例不红。
4. **防回归**：补一条**先红后绿**的测试；在 `docs/process/要点-<日期>.md` 记一行根因。

## 本项目附加规矩

- 同一问题**失败两次** → 停，写 `债表` + 要点，报卡点（不许硬试第三次）。
- 不生成"修复命令"让用户照着敲；错误必须带自查证据。
- 数据库/索引类问题：先用 `jingwei positions` 与 `graph stats` 判断是数据错还是判定错。

## 反模式

猜着改、一次改五处、把断言删掉、把 `unknown` 改成"没有"。
