# 数字不许手抄

## 判据

一个数字**能不能被自动核对**，决定它该写成精确值还是量级：

- 能核对（测试数、门禁数、图谱节点数）→ 写成 **fact 标记**（`fact:key` 那种注释包裹），由真源门禁看守；
- 不能核对（代码行数、耗时）→ **只说量级**（"四万多行"），并在旁边写明"什么时候量的"。

## 为什么

- 手抄错过三次（门禁 7/8、测试数、`演示脚本` 的"七道"）。
- 演示脚本里**图谱规模与代码行数**那几个数字全部过期（当时是凭印象写的，实测各不相同）——它们都该走 fact 或只写量级。
- 行数随手一改就漂，所以只敢说量级；节点数走 fact 标记，门禁盯着。

## 不适用

- **历史记录**（复盘、事故账本里的"当时是 330 条"）——那是事实快照，不该被追着改。

## 守卫

`checkDocFacts`（85 处 fact 逐个等于 facts.json）· `check-docs.mjs`（14 条「声明 N 项」）
