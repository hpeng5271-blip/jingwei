# 量具先怀疑

## 判据

当结论是"**没有 / 不存在 / 不对**"时，先查三样，再下结论：

1. **位置**——我搜的目录对不对（曾只扫 `understand/` 就报"找不到"）；
2. **名字**——`pwsh` vs `powershell`、`--help` 退出码不是"命令存在"的证据；
3. **出口**——我看的是哪个字段/哪个计数器（`doctor` 的"问题 3 条"不是"项目检查 0 条"）。

## 为什么

同一天同一形状 4 次：`doctor` 计数器看错、`checkCrateTable` 没 export、Rust 分支"测过了"、后台作业"死了"。
**四次都是把"我的量具没读到"当成"那个东西不存在"。**

## 不适用

- 已经**同一路径验证两次都为空**时，就该下结论了——否则会陷入无限自证。

## 守卫

`中文路径里_rust_只是提示_c_才警告`（补强为"必须说到那一句"）· `五个格子的和必须等于文件总数`（守恒，防漏格）
