# `tools/llm/` — 降本增效的四个小工具

> 目标：**只在"最硬的那层思考"上花钱**，其余留在 flash；并且"喂了多少"是可数的。

## 谁用哪个模型

| 角色 | 模型 | 谁决定 |
|---|---|---|
| 主会话（执行：改代码、跑门禁、读文件） | `deepseek-flash` | 会话创建时绑定 |
| 硬决策咨询（审计、架构、判据、卡点） | `deepseek-v4-pro` | 按规则触发，单次调用 |

## 何时升级（四条，缺一不升级）

1. 改**不可逆**的东西：schema 迁移、门禁判据、数据模型、删功能；
2. **连续失败 2 次**；
3. **人点名**："深想一下 / 定方案 / 这个架构怎么选"；
4. 影响 ≥3 个文件且门禁覆盖不到。

其余一律 flash。**不确定就不升级。**

## 四个工具

| 文件 | 作用 | 常用命令 |
|---|---|---|
| `digest.mjs` | 生成 ≤2000 tokens 的项目摘要 | `node tools/llm/digest.mjs` |
| `slice.mjs` | 按行号/grep 取代码片段，超 8K 直接报错 | `node tools/llm/slice.mjs crates/engine/src/graph/store.rs --grep "pub fn upsert"` |
| `caps.mjs` | 价格、单次上限（8K/2K）、日限（20 次 / ¥3） | 被其他三个引用 |
| `ledger.mjs` | 每次调用记一行，落 `%LOCALAPPDATA%\jingwei\llm-ledger.jsonl` | `node tools/llm/ledger.mjs`（打印今日用量） |

## 价格（官方页，2026-10 抓取）

`deepseek-v4-pro`：输入 4.5（空闲）/ 9.0（高峰）元/M，输出 13.5 / 27.0 元/M。
`deepseek-flash`：输入 1.0 / 2.0，输出 4.0 / 8.0。
高峰 = 工作日 9:00–12:00、14:00–18:00（北京时间）。

**一次咨询（8K 入 + 2K 出）≈ ¥0.06（空闲）/ ¥0.13（高峰）。**

## 为什么不能"整个会话切 pro"

你 15 天账单里 **63.6% 是输入·缓存命中**，而 pro 的缓存命中价是 flash 的 **7.5 倍**。
整会话切 pro ≈ 账单 ×3–7；按次咨询 ≈ 账单几乎不变。

## 纪律

- pro 只**读**，不改仓库；结论必须带"可验证的下一步"；
- 每次升级必须记账，**日限 20 次 / ¥3**，超了抛错；
- 输入超 8K → 切片或拆任务，**不许硬塞**。
